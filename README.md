# Audio LoopBack

برنامج بسيط بلغة Python بيعمل نقل مباشر (Real-time) للصوت من المايك إلى السماعة، من غير أي تسجيل أو حفظ - يعني بتسمع صوتك بنفسك لحظيًا وانت بتتكلم.

## المتطلبات

- Python 3.x
- مكتبة sounddevice

## التثبيت

```bash
pip install sounddevice
```

## التشغيل

```bash
python main.py
```

اضغط `Ctrl+C` لإيقاف البرنامج.

## طريقة العمل

البرنامج بيفتح قناة صوت مباشرة (Stream) بين المايك والسماعة الافتراضيين في الجهاز، وبينسخ أي صوت داخل من المايك ويطلعه في السماعة على طول.
